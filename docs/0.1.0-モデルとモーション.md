# HoloMapPerspective 試作版 — 導入・モデル・モーション・設置

## 1. このプラグインでできること

- Paper 1.21.11 / Java 21 の**サーバーだけ**に導入（クライアント側MODなし）。
- 壁に額縁と地図を自動設置し、その地図を3Dモデルの表示窓として使う。
- **プレイヤーの立ち位置によって、モデルを別角度から見る**。プレイヤーごとに別画像を計算する。
- お試しの踊るロボット「`demo`」が最初から内蔵されている。
- 外部のOBJモデルを追加する。アニメーションはOBJファイルの連番を読み込む。
- 1×1～3×3の地図を設置できる。

**注意：2026-11-06時点の実験版。描画計算の単体テストは完了していますが、
実際のPaperサーバーへの導入試験は未実施です。負荷が高い場合は1×1、5fpsから。**

## 2. インストール

1. `HoloMapPerspective-0.1.0.jar` をPaperサーバーの `plugins/` に置く。
2. サーバーを再起動。
3. OP権限のあるプレイヤーでログイン。
4. 垂直な壁（石など）を用意する。**額縁が付く面の前は空気ブロック**にする。
5. 地図の**左下にする壁ブロック**へ照準を合わせ、チャットに下記を入力する。

```mcfunction
/holomap place 1 1 demo
```

自動で見えない額縁と地図が設置される。左右に移動して視差を確認する。

2×2の地図にしたい場合は、左下のブロックを狙って以下を入力する。

```mcfunction
/holomap place 2 2 demo
```

壁は横2・縦2ブロックが必要。設置位置は自動計算される。

## 3. 操作コマンド

| コマンド | 動作 |
|---|---|
| `/holomap place 1 1 demo` | デモロボットを設置する |
| `/holomap place 2 2 crystal` | 2×2サイズでcrystalを設置（crystalは別途コピー） |
| `/holomap list` | 設置した表示のID一覧 |
| `/holomap remove 1` | ID 1の額縁を撤去 |
| `/holomap models` | 利用できるモデル一覧 |
| `/holomap model 1 crystal` | ID 1のモデルをcrystalに変更 |
| `/holomap reload` | `config.yml`・モデルファイルを読み直す |

## 4. 3Dモデルはどこから持ってくるの？

内蔵モデル以外は自分で用意する。ゲームや動画から無断でモデルを抜き出すのではなく、
**配布・利用条件が適合する3Dモデル**を使う。

よく見かける形式は `PMX`（MMD）、`VRM`（VTuber等）、`FBX`、`glTF/GLB`、`OBJ` など。
初期版は **OBJのみ直接読める**。その他はBlenderと各形式の読み込み用アドオンでインポートし、
OBJに変換する。

### 静止モデルの例

このZIPに入れたサンプル `examples/models/crystal/` を、サーバー内の次の場所にコピー。

```text
plugins/
└─ HoloMapPerspective/
   └─ models/
      └─ crystal/
         ├─ model.obj
         └─ crystal.mtl
```

その後サーバー上で：

```mcfunction
/holomap reload
/holomap place 1 1 crystal
```

Blenderのモデルなら、オブジェクトをOBJでエクスポートして `model.obj` にする。
**注意：画像テクスチャ（UV＋PNG）の表示はまだ未対応。** MTLの拡散色`Kd`は反映できる。
目・服・髪の細かな模様を再現するにはテクスチャ対応を追加する必要がある。

## 5. ダンス・モーションをどうやって入れる？

プラグイン側でMMDの`VMD`や骨格アニメーションを直接再生するわけではない。
**Blenderでモーションをキャラクターに適用して、各時刻の形状をOBJとして出力する方式**を採用。

1. Blenderにモデルを読み込む（必要ならVRM/MMD対応アドオン）。
2. アニメーションを読み込む。MMDならVMD、リグが適合するならFBXのモーションなど。
3. Blender上で正常に再生できるか確認する。モーションのリターゲットが必要な場合あり。
4. 保存した`.blend`に対し、付属スクリプト `tools/export_obj_animation.py` を実行する。

```bash
blender -b dance.blend -P tools/export_obj_animation.py -- --output mydance/frames --start 1 --end 60 --step 3
```

下記のようなフォルダができるので `models/mydance/` に移動する。

```text
models/mydance/
└─ frames/
   ├─ 0000.obj
   ├─ 0000.mtl
   ├─ 0001.obj
   ├─ 0001.mtl
   ├─ 0002.obj
   └─ ...
```

`/holomap reload` → `/holomap model 1 mydance` で切り替える。

動画のような初音ミク系の高品質モデルを使う場合、モデル・モーションそれぞれの
ライセンスを確認する。再配布やゲームへの組み込みを禁止する配布モデルもある。

## 6. 設定と制約

`plugins/HoloMapPerspective/config.yml` の初期値：

- `render-fps: 5`：視点に応じた地図画像の再計算頻度。
- `animation-fps: 10`：連番OBJの再生速度。
- `model-scale: 0.82`：地図の縦幅に対するモデルの大きさ。
- `model-depth: 0.75`：モデルが地図の後ろにある距離（ブロック数）。
- `max-triangles: 6000`、`max-animation-frames: 120`：初期版の制限。

この試作版は、Paperのプレイヤー別マップ描画API（`MapRenderer(true)`）を利用する。
実際に額縁の地図が何fpsで更新されるかはゲーム側の仕様に依存する。
高fps・高解像度の動画を表示するには、表示パケットの差分更新などを追加する必要がある。

**実装・テスト状況：** Javaソースの構文コンパイルおよび外部OBJを使った投影変化のテストは成功。
ただし公式Paper API JARがこのビルド環境で直接取得できず、互換シグネチャを持つ
検査用APIを使用してコンパイルした。配布JARは**Paper 1.21.11実サーバー未検証**。
正常表示しない場合はPaper実機でのログ・描画状況に基づく修正が必要。
