## 確認できていない範囲

Minecraftクライアントのゲーム画面を使う目視確認は未実施です。Windowsの画面操作機能が利用できませんでした。実サーバーテストのPlayerとMapCanvasは、視点の入力と画素の出力を制御するテスト用オブジェクトです。実際にログインしたクライアントへの地図パケット受信、画面上の透過・面のつながり・体感fpsは確認していません。

この記録は上記環境でのビルド・サーバー処理・計算結果を確認したものです。他バージョン、クライアントMOD、シェーダー、多人数・大面積での性能は検証対象に含みません。

## 再検証

ソースフォルダーで実行します。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-25'
.\gradlew.bat build
python tools\check_server.py
```

実サーバー用の検証プラグインは `gradlew.bat verificationJar` で作成できます。使い捨てのテストワールドでのみ使用してください。座標128～224、Y=128に設置・撤去用のデータを作ります。最初の起動の `PHASE_1_PASS` の後に保存して停止・再起動すると、約22秒後に `ALL_PASS` を出力します。テストが完了したら検証用JARを取り外します。

公式情報：[Paperの起動条件](https://docs.papermc.io/paper/getting-started/)、[Downloads API](https://docs.papermc.io/misc/downloads-service/)、[26.3 API](https://jd.papermc.io/paper/26.3/)。
